# SultanRevitMCP

This repo teaches AI agents to model assemblies that the Samaya Factory workshop can make and the site team can install. For Revit work, read [the Samaya Revit skill](skills/samaya-revit/SKILL.md). For fabrication work, start with [fabrication modeling](skills/samaya-revit/references/fabrication-modeling.md) and the trade reference. For costing work, read [the Samaya costing skill](skills/samaya-costing/SKILL.md).

For fabrication, select the trade skill listed in the Samaya Revit skill. Keep lessons where the carpenter, welder, CNC operator, or factory team will use them. Add a trade skill when verified lessons justify a distinct workflow.

## Keep the skills current

Before finishing a SultanRevitMCP or Samaya Revit task, check for a verified lesson about how to make, assemble, fit or check the work, or a standard corrected by the user. Record bridge troubleshooting when it affects that workflow. If it applies to future work, update the matching trade skill or the reference it uses in the same session. Search the existing references first and revise overlapping guidance in place. Keep project-specific values, private model details, credentials and raw session logs out of the shared skills.

Review the diff and commit and push the skill update with the repository's normal workflow. If another session provides evidence of an earlier lesson, apply the same check before adding it.
