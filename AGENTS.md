## Keep the skills current

Before finishing a SultanRevitMCP or Samaya Revit task, check for a verified workflow, a failure with a confirmed fix, or a standard corrected by the user. If it applies to future work, update the matching skill reference in the same session. Search the existing references first and revise overlapping guidance in place. Keep project-specific values, private model details, credentials and raw session logs out of the shared skills.

Review the diff and commit and push the skill update with the repository's normal workflow. If another session provides evidence of an earlier lesson, apply the same check before adding it.
