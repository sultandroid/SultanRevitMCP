# Preliminary structural screen for fabrication items

Use this reference before a full structural calculation for signs, frames, hoardings, showcases, brackets, gates and similar factory assemblies. It identifies whether the proposed arrangement needs redesign or formal engineering. It does **not** authorise fabrication, drilling or installation.

## Inputs that must be known

Record the item mark, overall geometry, self-weight, centre of gravity, support points, support substrate, intended anchor family, environmental exposure, wind/seismic/site actions where applicable, imposed loads, operating positions and the governing code/design basis. Use surveyed dimensions for a retrofit condition.

If a source is product-dependent, retain the current manufacturer source: anchor data sheet and installation instructions, sign module/driver data sheet, proprietary bracket data, and any selected fixing design output. A generic catalogue image is not a design input. Record whether the product is a candidate or an approved project selection.

## Screen sequence

1. **Load path:** sketch the transfer from applied load through sign or item, brackets, anchors and substrate to the structure. Flag a disconnected path, unsupported cantilever, thin finish-only support or inaccessible anchor.
2. **Geometry and stability:** identify the largest unsupported span, cantilever, eccentricity, slender members, torsion and overturning. Check the item in operating and maintenance positions, not only closed/resting position.
3. **Serviceability:** set a project limit for visible deflection, vibration, face distortion, door/gate movement and alignment. Movement that cracks a finish, opens a joint or affects sign lighting is a screen failure even if strength appears adequate.
4. **Preliminary member and connection demand:** calculate transparent, labelled screening demand using stated loads and combinations. Check only against a verified material/property source. Record units, load factors, restraint assumptions and the governing combination.
5. **Anchor feasibility:** confirm substrate evidence, edge distance, spacing, embedment zone, reinforcement conflict, installation access and corrosion/fire/environment compatibility. Do not assign anchor capacity before these conditions are verified.
6. **Decision:** state `PROCEED TO FORMAL DESIGN`, `REVISE CONFIGURATION`, or `HOLD FOR SITE / DESIGN INPUT`. A formal calculation is required when the screen exposes a critical condition, the item is public-facing/safety-critical, an anchor is structural, or the contract/authority requires it.

## Conditional anchor design

An anchor detail becomes design-ready only after the designer has verified the substrate type, thickness/strength, reinforcement or void condition, loads and eccentricity, anchor approval, edge distance, spacing, embedment, installation method and inspection/testing requirements. Until then, use a conditional anchor zone and a hold point on the sheet. Never show a generic anchor pattern as installable.

## Deliverable and boundary

Keep the screen as a short calculation note or controlled design-review record. Include the item mark, drawing revision, input table, load path sketch, screen calculations, outcome, hold points and required next action. Use the full [Samaya structural calculation report](../../samaya-structural-calc/SKILL.md) for the formal analysis and report.

The workshop may fabricate parts that are independent of unresolved anchors only when the issued package clearly separates them. Field drilling, anchor installation and final loading remain on hold until the approved structural/anchor detail and site verification are available.
