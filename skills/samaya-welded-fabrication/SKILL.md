# Model for the welder

Read [fabrication modeling](../samaya-revit/references/fabrication-modeling.md). For temporary fences, read [metal hoarding](../samaya-revit/references/metal-hoarding.md) and use the approved design for the job.

1. Use the approved section, material grade, wall thickness, and plate thickness. Model each piece the shop cuts or forms. Put the actual ends of tubes, angles and braces at the joint. Model a mitre, cope, plate or cutback where it changes the part. Check for unintended overlap at every connection.
2. Model bolt and anchor holes from the approved connection. Show the joint faces and where the weld goes. Carry the approved weld type, size, length and extent into the detail. Ask for the connection detail if any of these affect the work and are missing. Weld sizes in the hoarding examples belong to those designs.
3. Split the model into shop assemblies and site connections. Check fit-up and access to weld or tighten the connection in assembly order. For a gate, check the leaf swing with the hinges, latch, stops, stays, and nearby work in place.
4. Check member marks, cut lengths, end angles, plate orientation, and hole positions against the model. Detail any joint that the welder cannot read from the main views. Use the CNC skill for flat plates that need cut files.
